## 🔧 Installation & Utilisation

### Option 1 : Utiliser Localement
1. Clonez le repository
```bash
git clone https://github.com/votre-username/portfolio.git
cd portfolio
```

2. Ouvrez `index.html` dans votre navigateur
```bash
open index.html  # macOS
start index.html # Windows
```

### Option 2 : Déployer sur GitHub Pages
1. Poussez le code sur GitHub
```bash
git push origin main
```

2. Allez dans **Settings** → **Pages**
3. Sélectionnez `main` branch comme source
4. Votre portfolio sera accessible à : `https://votre-username.github.io/portfolio`

## 🎨 Personnalisation

### Changer les Couleurs
Modifiez les variables CSS dans `css/style.css` :
```css
--primary: #5b9bd5;      /* Bleu principal */
--background: #171e24;   /* Fond sombre */
--foreground: #eef1f3;   /* Texte clair */
```

### Ajouter des Sections
1. Ajoutez une nouvelle section dans `index.html`
2. Créez les styles correspondants dans `css/style.css`
3. Ajoutez le lien de navigation dans le header

### Mettre à Jour le Contenu
Modifiez directement le contenu HTML dans `index.html`.
